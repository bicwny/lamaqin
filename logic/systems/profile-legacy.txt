
# PROFILE SYSTEM LOGIC - Buddhist Practice App

## OVERVIEW
The profile system manages user account information, personal details, and settings within the Buddhist practice app. It handles user registration, profile setup, editing capabilities, and authentication state management with a focus on Buddhist community features.

## 1. CORE PROFILE ARCHITECTURE

### 1.1 Database Structure
```
profile_system:
├── users (用户基础表)
└── auth.users (Supabase认证表)
```

### 1.2 Entity Relationships
```sql
users:
- id (UUID, primary key, references auth.users)
- email (用户邮箱, unique)
- dharma_name (法名, nullable)
- lay_name (俗名, required for completion)
- class_name (当前班级, nullable)
- location (所在地区, required for completion)
- practice_years (修行年限, nullable)
- bio (个人简介, nullable)
- avatar_url (头像链接, nullable)
- created_at (创建时间)
- updated_at (更新时间)

auth.users (Supabase Auth):
- id (UUID, primary key)
- email (邮箱)
- email_confirmed_at (邮箱验证时间)
- user_metadata (用户元数据)
  └── dharma_name (法名存储)
```

### 3.1 User Registration & Setup Flow

#### Step 1: Email Authentication
```typescript
const RegistrationFlow = {
  emailVerification: async (email: string, dharmaName?: string) => {
    // Send OTP code to email
    const { error } = await supabase.auth.signInWithOtp({
      email,
      options: {
        shouldCreateUser: true,
        data: {
          dharma_name: dharmaName || null
        }
      }
    });
    
    if (error) throw new Error(error.message);
    
    // Navigate to email verification screen
    router.push({
      pathname: '/auth/email-verification',
      params: { email, dharmaName }
    });
  },
  
  verifyOTP: async (email: string, token: string) => {
    const { data, error } = await supabase.auth.verifyOtp({
      email,
      token,
      type: 'email',
    });
    
    if (error) throw new Error(error.message);
    
    if (data.user) {
      // Create user record in database
      await ensureUserInDatabase(data.user);
      
      // Navigate to profile setup
      router.replace('/profile-setup');
    }
  }
};
```

const ProfileSetupFlow = {

const AvatarGenerator = {
  generateFromDharmaName: (dharmaName?: string) => {
    if (!dharmaName) {
      return { text: '🙏', backgroundColor: '#FF6B6B' };
    }
    
    // Extract first character for avatar display
    const firstChar = dharmaName.charAt(0).toUpperCase();
    
    // Generate consistent color based on name
    const colors = ['#FF6B6B', '#4ECDC4', '#45B7D1', '#96CEB4', '#FFEAA7', '#DDA0DD'];
    const colorIndex = dharmaName.charCodeAt(0) % colors.length;
    
    return {
      text: firstChar,
      backgroundColor: colors[colorIndex]
    };
  },
  
  Avatar: ({ dharmaName, size = 50 }) => {
    const { text, backgroundColor } = AvatarGenerator.generateFromDharmaName(dharmaName);
    
    return (
      <View style={[
        styles.avatar,
        { 
          width: size, 
          height: size, 
          backgroundColor,
          borderRadius: size / 2 
        }
      ]}>
        <Text style={[styles.avatarText, { fontSize: size * 0.4 }]}>
          {text}
        </Text>
      </View>
    );
  }
};

### 5.2 Form Validation & UI

#### Real-time Validation
```typescript
const ProfileFormValidation = {
  validateField: (fieldName: string, value: string) => {
    const rules = ProfileValidation[fieldName];
    if (!rules) return { valid: true };
    
    // Required field validation
    if (rules.required && !value.trim()) {
      return {
        valid: false,
        message: `${getFieldDisplayName(fieldName)}是必填项`
      };
    }
    
    // Length validation
    if (rules.maxLength && value.length > rules.maxLength) {
      return {
        valid: false,
        message: `${getFieldDisplayName(fieldName)}不能超过${rules.maxLength}个字符`
      };
    }
    
    // Custom validation
    if (rules.validation) {
      return rules.validation(value);
    }
    
    return { valid: true };
  },
  
  validateAllFields: (formData: any) => {
    const errors = {};
    
    Object.keys(formData).forEach(fieldName => {
      const validation = ProfileFormValidation.validateField(fieldName, formData[fieldName]);
      if (!validation.valid) {
        errors[fieldName] = validation.message;
      }
    });
    
    return {
      valid: Object.keys(errors).length === 0,
      errors
    };
  }
};
```

## 6. DATA SYNCHRONIZATION & PERSISTENCE

### 6.1 Database-Auth Sync Strategy

#### Dual Storage Approach
```typescript
const DataSyncStrategy = {
  // Store critical data in both places for reliability
  dualStore: async (userId: string, userData: any) => {
    const promises = [
      // Primary storage: Database
      supabase
        .from('users')
        .upsert({
          id: userId,
          ...userData,
          updated_at: new Date().toISOString()
        }),
      
      // Secondary storage: Auth metadata (for quick access)
      supabase.auth.updateUser({
        data: {
          dharma_name: userData.dharma_name,
          lay_name: userData.lay_name,
          class_name: userData.class_name,
          location: userData.location
        }
      })
    ];
    
    // Execute both operations
    const results = await Promise.allSettled(promises);
    
    // Check for errors
    const dbResult = results[0];
    const authResult = results[1];
    
    if (dbResult.status === 'rejected') {
      console.error('Database update failed:', dbResult.reason);
      throw new Error('数据库更新失败');
    }
    
    if (authResult.status === 'rejected') {
      console.warn('Auth metadata update failed:', authResult.reason);
      // Don't fail the operation for auth metadata issues
    }
    
    return { success: true };
  },
  
  // Ensure user exists in database
  ensureUserInDatabase: async (authUser: any) => {
    try {
      console.log('🔍 Ensuring user exists in database:', authUser.email);
      
      // Check if user exists
      const { data: existingUser } = await supabase
        .from('users')
        .select('id')
        .eq('id', authUser.id)
        .maybeSingle();
      
      if (!existingUser) {
        console.log('🆕 Creating new user in database');
        const { error } = await supabase
          .from('users')
          .insert({
            id: authUser.id,
            email: authUser.email,
            dharma_name: authUser.user_metadata?.dharma_name || null,
            created_at: new Date().toISOString()
          });
        
        if (error && error.code !== '23505') { // Ignore duplicate key errors
          throw error;
        }
      }
      
      console.log('✅ User exists in database');
    } catch (error) {
      console.error('❌ Error ensuring user in database:', error);
      // Don't fail auth process for database sync issues
    }
  }
};
```

### 6.2 Error Handling & Fallback

#### Network Error Management
```typescript
const ProfileErrorHandling = {
  handleProfileLoadError: async (userId: string, error: any) => {
    console.error('❌ Profile loading error:', error);
    
    // Determine error type
    let errorMessage = '网络连接异常，使用本地数据';
    if (error.name === 'AbortError') {
      errorMessage = '请求超时，使用本地数据';
    } else if (error.message?.includes('Failed to fetch')) {
      errorMessage = '网络连接失败，使用本地数据';
    }
    
    // Try to get fallback data from auth context
    const { user } = useAuth();
    if (user) {
      const fallbackProfile = {
        id: user.id,
        email: user.email,
        dharma_name: user.dharma_name || '未设置法名',
        lay_name: null,
        location: null,
        class_name: null,
        practice_years: null,
        bio: null,
        created_at: new Date().toISOString(),
        updated_at: new Date().toISOString()
      };
      
      return {
        profile: fallbackProfile,
        error: errorMessage,
        isOfflineData: true
      };
    }
    
    throw error;
  },
  
  retryProfileLoad: async (userId: string, maxRetries: number = 3) => {
    let lastError;
    
    for (let attempt = 1; attempt <= maxRetries; attempt++) {
      try {
        console.log(`🔄 Profile load attempt ${attempt}/${maxRetries}`);
        
        const { data, error } = await supabase
          .from('users')
          .select('*')
          .eq('id', userId)
          .single();
        
        if (error) throw error;
        
        console.log('✅ Profile loaded successfully on retry');
        return { profile: data, error: null };
      } catch (error) {
        lastError = error;
        console.warn(`⚠️ Retry ${attempt} failed:`, error.message);
        
        if (attempt < maxRetries) {
          // Wait before retry (exponential backoff)
          await new Promise(resolve => setTimeout(resolve, 1000 * attempt));
        }
      }
    }
    
    // All retries failed
    return ProfileErrorHandling.handleProfileLoadError(userId, lastError);
  }
};
```

## 7. AUTHENTICATION INTEGRATION

### 7.1 Logout & Session Management

#### Comprehensive Logout Process
```typescript
const ProfileAuthIntegration = {
  handleLogout: async () => {
    try {
      console.log('🚪 Starting profile logout process');
      
      // Clear user state immediately
      setUser(null);
      setLoading(true);
      
      // Clear all storage locations
      await Promise.all([
        // AsyncStorage (React Native)
        AsyncStorage.removeItem('@auth_token'),
        AsyncStorage.removeItem('@user_session'),
        AsyncStorage.removeItem('sb-repl-auth-token'),
        
        // Supabase session
        supabase.auth.signOut({ scope: 'global' })
      ]);
      
      // Clear web storage if available
      if (typeof window !== 'undefined') {
        window.localStorage.clear();
        window.sessionStorage.clear();
      }
      
      console.log('✅ Profile logout completed');
      
      // Navigate to root (let index handle routing)
      router.replace('/');
    } catch (error) {
      console.error('❌ Profile logout error:', error);
      // Force clear state even on error
      setUser(null);
      router.replace('/');
    } finally {
      setLoading(false);
    }
  },
  
  // Navigate after logout based on app state
  postLogoutNavigation: () => {
    // The root index.tsx will handle routing:
    // No user -> /auth/unified
    // User without complete profile -> /profile-setup
    // User with complete profile -> /(tabs)
    router.replace('/');
  }
};
```
