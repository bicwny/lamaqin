
# Project Configuration Feature

## Overview
The project configuration system allows users to create customized practice projects with flexible goals, durations, and tracking methods.

## Configuration Options

### Practice Type Selection
- Time-based practices (meditation sessions)
- Count-based practices (mantras, prostrations)
- Hybrid approaches

### Goal Setting
- Daily targets
- Weekly objectives
- Total project goals
- Ongoing vs. fixed duration

### Duration Options
- 7 days, 21 days, 49 days, 100 days
- Custom duration
- Ongoing practice (no end date)

### Target Configuration
- Session-based targets (for time practices)
- Count-based targets (for repetition practices)
- Flexible adjustment during project

## Implementation Flow
1. Practice type selection
2. Goal configuration
3. Duration setting
4. Project naming
5. Target calculation
6. Database record creation
7. Progress tracking initialization

## Advanced Features
- Preset project names
- Smart target calculation
- Progress prediction
- Adaptive goal adjustment
