
# Phase 3.2: Component Migration Templates Implementation

## Overview
Created comprehensive migration templates and utilities to systematically migrate components from Colors.ts to DesignSystem.ts tokens.

## Files Created/Modified

### 1. utils/migrationTemplates.ts
- **MigrationTemplates**: Complete pattern templates for buttons, cards, inputs, text, layouts, progress bars, and modals
- **MigrationUtils**: Helper functions for pattern matching, color migration, spacing migration, and full transformations
- **FileMigrationTemplates**: Specific templates for practice-detail, modal-template, and study screens
- **ImportReplacements**: Systematic import and reference replacement patterns

### 2. utils/fileMigrationHelpers.ts
- **PracticeDetailMigration**: Specialized migration helper for practice-detail screen
- **FileTransformer**: Complete file transformation utilities
- **Migration reporting**: Generates detailed migration reports

## Key Features Implemented

### Template System
```typescript
// Button templates
primary: {
  oldPattern: { backgroundColor: '#da4347', ... },
  newPattern: { ...ComponentTokens.button.primary },
  apply: () => componentHelpers.getButtonStyle('primary'),
}
```

### Systematic Transformations
- **Color Migration**: Hardcoded hex values → DesignSystem.colors tokens
- **Spacing Migration**: Hardcoded pixels → DesignSystem.spacing tokens  
- **Pattern Recognition**: Automatic old pattern detection and replacement
- **Import Updates**: Colors.ts → DesignSystem.ts + ComponentTokens + Typography

### File-Specific Helpers
- **Practice Detail**: Specialized templates for the most complex screen
- **Modal Template**: Common modal patterns
- **Study Screen**: Course card and progress bar patterns

## Usage Examples

### Apply Button Template
```typescript
// Old way
const buttonStyle = {
  backgroundColor: '#da4347',
  paddingVertical: 16,
  paddingHorizontal: 20,
  borderRadius: 12,
};

// New way
const buttonStyle = MigrationTemplates.button.primary.apply();
```

### Transform File Content
```typescript
const transformedContent = FileTransformer.transformFile(
  originalContent, 
  'practice-detail.tsx'
);
```

### Generate Migration Report
```typescript
const report = FileTransformer.generateMigrationReport(
  originalContent,
  transformedContent,
  'practice-detail.tsx'
);
```

## Error Resolution
This implementation specifically addresses the console error:
```
"Uncaught ReferenceError: Colors is not defined"
```

By providing:
1. **Import replacement** templates to systematically update all Colors.ts imports
2. **Reference replacement** patterns to update all Colors.* references
3. **Complete migration** utilities to transform entire files
