## 核心功能特色总结

### **1. 修行记录系统**
- **四种添加方式**：加入主题、单独修法、每日功课、一次性记录
- **渐进式主题启动**：可以逐个启动主题中的修法，避免一次性负担过重
- **修法三状态管理**：未启动 → 进行中 → 已完成（无暂停功能）
- **灵活操作**：[完成] 和 [自定义记录] 满足不同需求

### **2. 观修系统**
- **灵活计座**：支持多个短座合并，[增加座] 动态添加
- **智能验证**：总时长≥30分钟 或 每座≥15分钟且有2座以上
- **进度提醒**：显示需要补修的座次

### **3. 听课系统**
- **重复听课**：每课可多次学习，独立记录
- **简洁登记**：下拉选择 + 一键完成
- **智能推进**：完成后自动跳到下一课

### **4. 观心功能**
- **简化记录**：只记录善心/恶心
- **视觉化**：🤍善心、🖤恶心直观显示
- **趋势分析**：7天图表 + 月度统计

### **5. 一次性记录**
- **五大类型**：计数修法、观修、功课诵读、持戒记录、其他修行
- **完整统计**：计入总体数据和分享内容
- **灵活备注**：支持详细说明

### **6. 统计分析**
- **全面统计**：修、闻、观、戒四个维度
- **智能提醒**：观修进度缺失提醒
- **自动分享**：生成标准化修行总结

## 数据结构设计

### **核心表结构**
```sql
-- 用户信息
users (id, dharma_name, email, location, practice_years, class_name)

-- 修行体系
themes (id, name, description, type)
practices (id, name, type, unit)
courses (id, name, total_lessons, teacher)
course_lessons (id, course_id, lesson_number, title)

-- 用户修行项目
user_practice_projects (
  id, user_id, theme_id, practice_id,
  target_count, start_date, target_end_date,
  current_count, daily_target, 
  status -- 'not_started', 'active', 'completed'
)

-- 记录系统
daily_records (id, user_id, practice_project_id, record_date, count, notes)
meditation_records (id, user_id, practice_id, record_date, session_number, duration_minutes)
study_records (id, user_id, course_id, lesson_id, study_date, study_count_for_lesson)
mindfulness_records (id, user_id, record_date, record_time, mind_type)
one_time_records (id, user_id, record_date, practice_type, practice_name, count_or_duration, notes)
precept_records (id, user_id, precept_type, record_date, notes)
```

## 技术实现方案

### **推荐技术栈**
- **前端**：Expo + React Native
- **后端**：Supabase (PostgreSQL + Auth + Storage)
- **开发环境**：Replit
- **状态管理**：React Context + useState
- **UI组件**：React Native Elements

### **开发阶段规划**
1. **Phase 1 (MVP)**：用户认证 + 基础修法记录 + 简单统计
2. **Phase 2**：观修系统 + 听课系统 + 观心功能
3. **Phase 3**：主题管理 + 渐进式启动 + 一次性记录 + 完整统计

## 应用核心价值

这个完整设计涵盖了佛教修行的核心需求：**戒定慧三学**的全面记录和统计。通过数字化手段：

1. **渐进式修行管理** - 支持逐步启动修法，避免修行压力过大
2. **培养修行习惯** - 每日功课提醒和记录
3. **增强修行觉察** - 观心功能培养正念
4. **追踪修行进步** - 详细统计显示成长轨迹
5. **保持修行连续性** - 完整的历史记录和分享功能

既保持了传统修行的系统性和严谨性，又适应了现代修行者的数字化需求和个性化节奏。界面简洁直观，操作高效便捷，真正能够帮助修行者在日常生活中保持精进不懈的修行状态。
