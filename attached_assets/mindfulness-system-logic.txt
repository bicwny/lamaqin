
# Mindfulness System Logic & Functionality Documentation
# React Native Expo App - 修行追踪 (Practice Tracking)

## Overview
The mindfulness system (心性观察) is designed to help users observe and track their mental states throughout the day, distinguishing between wholesome (善心) and unwholesome (恶心) thoughts and emotions. This system promotes self-awareness and mindful observation of one's inner mental processes.

## Core Concepts

### 1. Mental State Categories
- **善心 (Good Mind/Wholesome States)**: Positive, beneficial mental states
  - Compassion, loving-kindness, patience, generosity
  - Mindful awareness, clarity, peace
  - Gratitude, joy, contentment
  - Wisdom, understanding, acceptance

- **恶心 (Bad Mind/Unwholesome States)**: Negative, harmful mental states
  - Anger, hatred, resentment, jealousy
  - Greed, attachment, craving
  - Ignorance, delusion, confusion
  - Pride, arrogance, fear, worry

### 2. Recording Philosophy
- **Non-judgmental observation**: Users observe mental states without harsh self-criticism
- **Immediate recording**: Capture mental states as they arise for accuracy
- **Pattern recognition**: Build awareness of mental habits over time
- **Progress tracking**: Monitor improvement in mental cultivation

## System Architecture

### Database Schema
```sql
-- Mindfulness Records Table
CREATE TABLE mindfulness_records (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    user_id UUID REFERENCES users(id) ON DELETE CASCADE,
    record_date DATE NOT NULL,           -- Date in user's timezone
    record_time TIME NOT NULL,           -- Time stored in UTC
    mind_type TEXT CHECK (mind_type IN ('good', 'bad')) NOT NULL,
    description TEXT,                    -- Optional user description
    created_at TIMESTAMP WITH TIME ZONE DEFAULT NOW()
);
```

### Data Flow
1. **User Input** → Mental state selection + optional description
2. **Timezone Processing** → Convert to appropriate timezone for storage
3. **Database Storage** → Store with proper date/time handling
4. **Statistics Generation** → Real-time calculation of daily stats
5. **Display** → Show formatted data with timezone awareness

## Functional Components

### A. Recording Interface
1. **Description Input Field**
   - Optional text area for context
   - Placeholder: "描述当前的心境或想法（可选）"
   - Multiline support (3 lines)
   - Preserved until successful recording

2. **Action Buttons**
   - **善心 Button**: Green (#10B981), records positive mental state
   - **恶心 Button**: Red (#EF4444), records negative mental state
   - Both buttons trigger immediate database recording

3. **User Experience Flow**
   ```
   User observes mental state → 
   (Optional) Adds description → 
   Selects 善心 or 恶心 → 
   System records with timestamp → 
   Description field clears → 
   Statistics update immediately
   ```

### B. Statistics Dashboard
1. **Today's Statistics Card**
   - **Good Count**: Number of 善心 records today
   - **Bad Count**: Number of 恶心 records today
   - **Good Percentage**: (Good / Total) × 100
   - **Visual Progress Bar**: Green fill representing good percentage

2. **Real-time Calculations**
   ```javascript
   const getTodayStats = () => {
     const good = todayRecords.filter(r => r.mind_type === 'good').length;
     const bad = todayRecords.filter(r => r.mind_type === 'bad').length;
     const total = good + bad;
     const goodPercent = total > 0 ? Math.round((good / total) * 100) : 0;
     return { good, bad, total, goodPercent };
   };
   ```

3. **Progress Visualization**
   - Horizontal progress bar
   - Green fill proportional to good percentage
   - Light red background (indicating areas for improvement)

### C. Timezone Management
1. **Daily Reset Logic**
   - Resets at midnight in user's local timezone
   - Automatic detection of timezone changes
   - Handles daylight saving time transitions

2. **Time Storage Strategy**
   - **record_date**: Stored in user's timezone (YYYY-MM-DD)
   - **record_time**: Stored in UTC (HH:MM:SS)
   - **Display**: Converted back to user's local time

3. **Timezone Display**
   - Shows current timezone name
   - Indicates daily reset time: "每日午夜12点重置"

## Data Processing Logic

### A. Recording Process
1. **Input Validation**
   - Ensure user is authenticated
   - Verify timezone information is available
   - Validate mind_type is either 'good' or 'bad'

2. **Timestamp Generation**
   ```javascript
   const today = getCurrentDateInTimezone(timezoneInfo.timezone);
   const now = new Date();
   const utcTime = now.toISOString().split('T')[1].split('.')[0]; // HH:MM:SS
   ```

3. **Database Insert**
   ```javascript
   await mindfulnessService.recordMindfulness({
     user_id: user.id,
     record_date: today,        // Local date
     record_time: utcTime,      // UTC time
     mind_type: mindType,       // 'good' or 'bad'
     description: description.trim() || undefined
   });
   ```

4. **Success Handling**
   - Show success toast notification
   - Clear description field
   - Refresh today's records
   - Update statistics immediately

### B. Data Retrieval
1. **Today's Records Query**
   ```javascript
   const records = await mindfulnessService.getTodayRecords(user.id, today);
   ```

2. **Date Validation**
   - Ensure proper date format (YYYY-MM-DD)
   - Handle timezone conversion errors gracefully
   - Fall back to empty array on invalid dates

3. **Time Display Conversion**
   ```javascript
   const formatTime = (timeString) => {
     const utcDate = new Date(`1970-01-01T${timeString}Z`);
     return utcDate.toLocaleTimeString('en-US', {
       timeZone: timezoneInfo?.timezone || 'UTC',
       hour12: false,
       hour: '2-digit',
       minute: '2-digit'
     });
   };
   ```

├── PageTemplate (Layout wrapper)

│   ├── StatsRow (Numerical stats)

### B. State Management
```javascript
// Component State
const [todayRecords, setTodayRecords] = useState<MindfulnessRecord[]>([]);
const [description, setDescription] = useState('');
const [loading, setLoading] = useState(true);

// Derived State
const stats = getTodayStats(); // Calculated from todayRecords

// External State
const { user } = useAuth(); // Authentication context
const { timezoneInfo, handleDailyResetCheck } = useTimezone(); // Timezone hook
```

### C. Effect Management
```javascript
useEffect(() => {
  loadTodayRecords(); // Initial data load
  
  // Daily reset handler
  if (user && timezoneInfo) {
    handleDailyResetCheck(() => {
      setTodayRecords([]);
      loadTodayRecords();
    });
  }
}, [user, timezoneInfo]);
```

## Conclusion

The mindfulness system provides a simple yet powerful tool for mental state awareness and cultivation. By combining immediate recording capabilities with meaningful statistics and timezone-aware daily resets, it supports users in developing greater self-awareness and mental clarity.

The system's design emphasizes:
- **Simplicity**: Easy, quick recording process
- **Accuracy**: Proper timezone and timestamp handling
- **Privacy**: Secure, user-controlled data
- **Growth**: Clear progress visualization
- **Mindfulness**: Non-judgmental observation and tracking

This foundation supports both individual practice development and potential integration with broader spiritual and meditation tracking systems.
