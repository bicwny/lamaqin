### Component Tokens Added

#### 1. Button Component Tokens
**5 Button Variants Created:**
- `primary` - Main action buttons (red dharma color)
- `secondary` - Outline buttons with primary border
- `small` - Compact secondary action buttons  
- `text` - Minimal text-only buttons for links
- `dharma` - Special Buddhist practice buttons

**Features:**
- Consistent padding patterns (16px vertical, 20px horizontal)
- Proper border radius (12px for primary/secondary)
- Typography integration (font sizes, weights, letter spacing)
- Shadow and elevation support
