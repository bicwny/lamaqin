### MIGRATION MAPPING

#### Font Size Migration Map
```
12px → DesignSystem.typography.fontSize.xs
14px → DesignSystem.typography.fontSize.sm  
16px → DesignSystem.typography.fontSize.base
18px → DesignSystem.typography.fontSize.lg
20px → DesignSystem.typography.fontSize.xl
24px → DesignSystem.typography.fontSize['2xl']
32px → DesignSystem.typography.fontSize['3xl']
```

#### Font Weight Migration Map
```
'500' → DesignSystem.typography.fontWeight.medium
'600' → DesignSystem.typography.fontWeight.semibold
'700' → DesignSystem.typography.fontWeight.bold
'bold' → DesignSystem.typography.fontWeight.bold
```

#### Letter Spacing Migration Map
```
-0.3 → DesignSystem.typography.letterSpacing.tight
-0.2 → DesignSystem.typography.letterSpacing.tight (closest match)
-0.1 → DesignSystem.typography.letterSpacing.normal (may need new token)
```

### SEMANTIC TYPOGRAPHY PATTERNS IDENTIFIED

#### 1. Heading Patterns
- **Large Headings**: 24px, weight 700, letterSpacing -0.3
  - Used for: practiceTitle, detailsSectionTitle, historyTitle
  - Maps to: `createStyles.heading('2xl')`

- **Medium Headings**: 18px, weight 700, letterSpacing -0.3  
  - Used for: progressText, emptyText
  - Maps to: `createStyles.heading('lg')`

#### 2. Body Text Patterns
- **Primary Body**: 16px, weight 400-500
  - Used for: practiceDescription, detailLabel, detailValue
  - Maps to: `createStyles.body('base')`

- **Secondary Body**: 14px, weight 500
  - Used for: practiceType, dailyTargetText, sessionDetails
  - Maps to: `createStyles.body('sm')`

- **Small Text**: 12px, weight 500
  - Used for: loadingText, recordTime, notesLabel
  - Maps to: `createStyles.body('xs')`

#### 3. Interactive Element Patterns
- **Primary Buttons**: 16px, weight 700, letterSpacing -0.2
  - Maps to: `DesignSystem.components.button.text.primary`

- **Secondary Buttons**: 14px, weight 600, letterSpacing -0.1
  - Maps to: `DesignSystem.components.button.text.secondary`

- **Links**: 14px, weight 600
  - Used for: viewAllText
  - Maps to: `createStyles.body('sm')` with semibold weight

### INCONSISTENCIES FOUND

#### 1. ThemedText vs Direct Styling
- **ThemedText.tsx** uses different font sizes than practice-detail
- **ThemedText** has 20px subtitle, but practice-detail uses 18px for similar headings
- **Line height** inconsistency: ThemedText uses 24/30/32, practice-detail uses 20/24

#### 2. Missing Design System Coverage
- **DesignSystem.ts** missing `-0.2` and `-0.1` letterSpacing values used in practice-detail
- **No semantic text styles** defined for buttons, links, captions

#### 3. Buddhist App Specific Needs
- **Practice names** need special typography treatment
- **Progress indicators** need consistent number styling
- **Record details** need hierarchical text styling

### SUCCESS CRITERIA FOR TYPOGRAPHY MIGRATION

#### Before Migration:
- 5+ different font size patterns
- 4+ different font weight applications  
- Inconsistent letter spacing usage
- Mix of hardcoded values and design tokens

#### After Migration:
- 100% usage of DesignSystem.typography tokens
- Consistent semantic typography patterns
- Zero hardcoded font values
- Performance-optimized createStyles usage
