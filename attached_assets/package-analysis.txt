## POTENTIALLY REDUNDANT PACKAGES

### 🟡 Questionable/Redundant
- react-native-elements: ^3.4.3 
  ⚠️ REDUNDANT - Old UI library, replaced by newer solutions
  ⚠️ You're using custom components and NativeWind instead

- react-native-vector-icons: ^10.2.0
  ⚠️ POTENTIALLY REDUNDANT - @expo/vector-icons already provides icons
  ⚠️ May cause conflicts on iOS/Android

- expo-symbols: ~0.4.5
  ⚠️ POTENTIALLY REDUNDANT - Limited to iOS, may cause Android issues

- expo-image: ~2.4.0
  ⚠️ QUESTIONABLE - React Native Image component is sufficient for most cases

- expo-system-ui: ~5.0.10
  ⚠️ QUESTIONABLE - Limited usage, may not be essential

- react-native-webview: ^13.13.5
  ⚠️ KEEP IF NEEDED - Only if you're using WebView for course content

### 🔧 Development Only
- @babel/traverse: ^7.28.0
  ⚠️ Should be in devDependencies, not production

- babel-plugin-module-resolver: ^5.0.2
  ⚠️ Should be in devDependencies

### 🌐 Web-Specific
- react-dom: 19.0.0
  ⚠️ Only needed for web builds, causes bundle bloat for mobile
- react-native-web: ~0.20.0
  ⚠️ Only needed for web builds

- @expo/ngrok: ^4.1.3
  ⚠️ Development only, should be in devDependencies

## COMPATIBILITY ISSUES

### iOS Specific (May cause Android issues)
- expo-symbols: ~0.4.5 ❌ iOS only, will fail on Android

### Potential Conflicts
- react-native-vector-icons vs @expo/vector-icons
  ❌ Both provide similar functionality, may conflict

### Version Mismatches
- React 19.0.0 with React Native 0.79.5
  ⚠️ Bleeding edge React version, may cause stability issues

## RECOMMENDED ACTIONS

### 1. Remove Redundant Packages
```bash
npm uninstall react-native-elements react-native-vector-icons expo-symbols @babel/traverse babel-plugin-module-resolver @expo/ngrok
```

### 2. Move Development Packages
```bash
npm uninstall @babel/traverse babel-plugin-module-resolver @expo/ngrok
npm install -D @babel/traverse babel-plugin-module-resolver @expo/ngrok
```

### 3. Consider Removing (if not used)
- expo-image (if using standard Image component)
- expo-system-ui (if not actively used)
- react-native-webview (if no WebView usage)

### 4. Web-Only Packages (remove for mobile-only)
If you're not supporting web:
```bash
npm uninstall react-dom react-native-web
```
