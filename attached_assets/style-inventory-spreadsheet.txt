## INCONSISTENCIES & MIGRATION PRIORITIES

### High Priority Issues
1. **Text Color Chaos**: 6+ different color values for similar text purposes
2. **Spacing Randomness**: Non-standard values like 6px, 10px radius
3. **Font Weight Mix**: String vs numeric values ('bold' vs '700')
4. **Hardcoded Colors**: Direct hex values instead of design tokens

### Medium Priority Issues
1. **Shadow Inconsistency**: Different shadow configs for similar components
2. **Border Radius Variance**: 6px, 10px values need standardization
3. **Line Height Gaps**: Missing consistent line height scale

### Migration Strategy by Risk Level

#### Low Risk (Start Here)
- Font size standardization (clear 1:1 mappings)
- Primary color token replacement
- Basic spacing standardization

#### Medium Risk
- Text color consolidation (requires semantic decisions)
- Font weight standardization
- Border radius cleanup

#### High Risk (Requires Design Review)
- Complex component pattern migrations
- Color semantic mapping decisions
- Component-specific spacing overrides
