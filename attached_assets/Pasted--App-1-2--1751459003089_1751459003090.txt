# 佛教修行追踪App - 完整界面规范（含认证系统）

## 应用整体架构

### **主要功能模块**
1. **用户认证**（登录、注册、个人资料设置）
2. **修行记录**（修法追踪、观修、主题管理）
3. **闻法学习**（听课登记）
4. **观心功能**（善恶心记录）
5. **进度统计**（个人数据分析）
6. **个人中心**（设置、持戒等）

## 核心功能特色总结

### **1. 认证系统**
- **温和的注册流程**：法名可选，降低佛教初学者门槛
- **个人资料完善**：修行偏好和课程兴趣匹配
- **邮箱验证机制**：确保账户安全性
- **优雅的UI设计**：佛教美学与现代设计融合

### **2. 修行记录系统**
- **四种添加方式**：加入主题、单独修法、每日功课、一次性记录
- **渐进式主题启动**：可以逐个启动主题中的修法，避免一次性负担过重
- **修法三状态管理**：未启动 → 进行中 → 已完成（无暂停功能）
- **灵活操作**：[完成] 和 [自定义记录] 满足不同需求

### **3. 观修系统**
- **灵活计座**：支持多个短座合并，[增加座] 动态添加
- **智能验证**：总时长≥30分钟 或 每座≥15分钟且有2座以上
- **进度提醒**：显示需要补修的座次

### **4. 闻思系统**
- **重复听课**：每课可多次学习，独立记录
- **简洁登记**：下拉选择 + 一键完成
- **智能推进**：完成后自动跳到下一课
- **详细进度**：课程完成度和学习历史

### **5. 心性功能**
- **简化记录**：只记录善心/恶心
- **视觉化**：🤍善心、🖤恶心直观显示
- **趋势分析**：7天图表 + 月度统计
- **观心日记**：详细记录心性变化过程

### **6. 一次性记录**
- **五大类型**：计数修法、观修、功课诵读、持戒记录、其他修行
- **完整统计**：计入总体数据和分享内容
- **灵活备注**：支持详细说明

### **7. 统计分析**
- **全面统计**：修、闻、观、戒四个维度
- **智能提醒**：观修进度缺失提醒
- **自动分享**：生成标准化修行总结
- **月度年度总结**：深度分析修行进展

### **9. 认证系统**
- **完整的认证流程**：注册、登录、邮箱验证、密码重置
- **首次登录引导**：欢迎页面和个人资料设置
- **安全密码管理**：修改密码（需当前密码）vs 重置密码（邮箱验证）
- **温和的注册体验**：法名可选，降低佛教初学者门槛
- **邮箱验证机制**：防止虚假注册，60秒重发限制

## 技术实现方案

### **推荐技术栈**
- **前端**：Expo + React Native (~53.0.9)
- **后端**：Supabase (PostgreSQL + Auth + Storage)
- **开发环境**：Replit
- **状态管理**：React Context + useState
- **UI组件**：React Native Elements
- **认证系统**：Supabase Auth with Email Verification

### **开发阶段规划**
1. **Phase 1 (认证+基础)**：用户认证 + 基础修法记录 + 简单统计
2. **Phase 2 (核心功能)**：观修系统 + 听课系统 + 观心功能
3. **Phase 3 (高级功能)**：主题管理 + 渐进式启动 + 一次性记录 + 完整统计
4. **Phase 4 (完善优化)**：分享系统 + 通知推送 + 数据导出 + 性能优化
