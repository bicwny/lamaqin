
# STUDY SYSTEM LOGIC - Buddhist Practice App

## OVERVIEW
The study system is designed for systematic Buddhist learning through structured courses and lessons. It supports multiple study methods and tracks progress through completion of both listening (听传承) and reading (看法本) components for each lesson.

## 1. CORE STUDY ARCHITECTURE

### 1.1 Database Structure
```
study_system:
├── courses (课程基础表)
├── course_lessons (课程章节表)
├── user_courses (用户课程注册表)
└── study_records (学习记录表)
```

### 1.2 Entity Relationships
```sql
courses:
- id (UUID, primary key)
- name (课程名称: "《入菩萨行论》", "《前行广释》")
- total_lessons (总课数)
- teacher (授课老师)
- description (课程描述)
- created_at

course_lessons:
- id (UUID, primary key)
- course_id (关联课程)
- lesson_number (课序号: 1, 2, 3...)
- title (课程标题: "第1课：菩提心的重要性")
- url (在线链接, nullable)
- created_at

user_courses:
- id (UUID, primary key)
- user_id (关联用户)
- course_id (关联课程)
- status ('active' | 'completed' | 'paused')
- joined_date (加入日期)
- completed_date (完成日期, nullable)
- progress_percentage (完成百分比: 0.00-100.00)
- created_at, updated_at

study_records:
- id (UUID, primary key)
- user_id (关联用户)
- course_id (关联课程)
- lesson_id (关联课程)
- study_date (学习日期)
- study_type ('听传承' | '看法本')
- study_count_for_lesson (该课学习次数)
- created_at
```

```typescript
const getNextLesson = async (userId: string, courseId: string) => {
  const studyRecords = await studyService.getUserStudyRecords(userId, courseId);
  
  // Group records by lesson
  const lessonCompletionMap = new Map();
  
  studyRecords.forEach(record => {
    if (!lessonCompletionMap.has(record.lesson_id)) {
      lessonCompletionMap.set(record.lesson_id, {
        听传承: false,
        看法本: false,
        lessonNumber: record.lesson.lesson_number
      });
    }
    
    const completion = lessonCompletionMap.get(record.lesson_id);
    completion[record.study_type] = true;
  });
  
  // Find first incomplete lesson
  const allLessons = await studyService.getCourseLessons(courseId);
  
  for (const lesson of allLessons) {
    const completion = lessonCompletionMap.get(lesson.id);
    
    if (!completion || !completion.听传承 || !completion.看法本) {
      return lesson;
    }
  }
  
  // All lessons completed
  return null;
};
```

### 3.2 Progress Calculation Logic

#### Lesson Completion Tracking
```typescript
const calculateCourseProgress = async (userId: string, courseId: string) => {
  // Get course metadata
  const course = await studyService.getCourse(courseId);
  
  // Get all study records for this course
  const studyRecords = await studyService.getUserStudyRecords(userId, courseId);
  
  if (!studyRecords || studyRecords.length === 0) {
    return 0;
  }
  
  // Group by lesson and check completion
  const lessonCompletionMap = new Map();
  
  studyRecords.forEach(record => {
    if (!lessonCompletionMap.has(record.lesson_id)) {
      lessonCompletionMap.set(record.lesson_id, {
        听传承: false,
        看法本: false,
        lessonNumber: record.lesson?.lesson_number || 0
      });
    }
    
    const lessonData = lessonCompletionMap.get(record.lesson_id);
    if (record.study_type === '听传承') {
      lessonData.听传承 = true;
    } else if (record.study_type === '看法本') {
      lessonData.看法本 = true;
    }
  });
  
  // Count fully completed lessons (both 听传承 AND 看法本)
  const completedLessons = Array.from(lessonCompletionMap.values()).filter(
    lesson => lesson.听传承 && lesson.看法本
  );
  
  // Calculate percentage
  const progressPercentage = (completedLessons.length / course.total_lessons) * 100;
  
  // Update user_courses table
  await supabase
    .from('user_courses')
    .update({
      progress_percentage: progressPercentage,
      status: progressPercentage >= 100 ? 'completed' : 'active',
      completed_date: progressPercentage >= 100 ? new Date().toISOString().split('T')[0] : null,
      updated_at: new Date().toISOString()
    })
    .eq('user_id', userId)
    .eq('course_id', courseId);
  
  return progressPercentage;
};
```

## 7. DATA PERSISTENCE & SYNC

### 7.1 Real-time Updates
```typescript
const StudyDataSync = {
  // Record study with immediate UI update
  recordStudyWithSync: async (studyData) => {
    // Optimistic update
    updateLocalState(studyData);
    
    try {
      // Persist to database
      await studyService.recordStudy(studyData);
      
      // Refresh progress calculations
      await studyService.calculateProgress(userId, courseId);
      
      // Trigger UI refresh
      setRefreshTrigger(prev => prev + 1);
    } catch (error) {
      // Rollback optimistic update
      revertLocalState(studyData);
      throw error;
    }
  },
  
  // Batch progress recalculation
  batchRecalculateProgress: async (userId: string) => {
    const userCourses = await studyService.getUserCourses(userId);
    
    for (const userCourse of userCourses) {
      await studyService.calculateProgress(userId, userCourse.course_id);
    }
    
    // Reload updated data
    const updatedCourses = await studyService.getUserCourses(userId);
    setUserCourses(updatedCourses);
  }
};
```

### 7.2 Progress Integrity
```typescript
const ProgressIntegrityCheck = {
  // Verify progress calculation accuracy
  verifyProgress: async (userId: string, courseId: string) => {
    const course = await studyService.getCourse(courseId);
    const studyRecords = await studyService.getUserStudyRecords(userId, courseId);
    
    // Manual calculation
    const manualProgress = calculateProgressManually(studyRecords, course.total_lessons);
    
    // Database stored progress
    const userCourse = await studyService.getUserCourse(userId, courseId);
    const storedProgress = userCourse.progress_percentage;
    
    // Check for discrepancy
    if (Math.abs(manualProgress - storedProgress) > 0.01) {
      console.warn('Progress discrepancy detected', {
        manual: manualProgress,
        stored: storedProgress,
        difference: Math.abs(manualProgress - storedProgress)
      });
      
      // Auto-correct if needed
      await studyService.calculateProgress(userId, courseId);
    }
    
    return { manual: manualProgress, stored: storedProgress };
  }
};
```

## 9. ERROR HANDLING & DATA VALIDATION

### 9.1 Study Recording Validation
```typescript
const StudyValidation = {
  validateStudyRecord: (recordData: any) => {
    const errors = [];
    
    if (!recordData.user_id) errors.push('用户ID必填');
    if (!recordData.course_id) errors.push('课程ID必填');
    if (!recordData.lesson_id) errors.push('课程ID必填');
    if (!recordData.study_date) errors.push('学习日期必填');
    if (!['听传承', '看法本'].includes(recordData.study_type)) {
      errors.push('学习类型必须是"听传承"或"看法本"');
    }
    
    if (errors.length > 0) {
      throw new Error(`学习记录验证失败: ${errors.join(', ')}`);
    }
    
    return true;
  },
  
  validateCourseEnrollment: async (userId: string, courseId: string) => {
    // Check if course exists
    const course = await studyService.getCourse(courseId);
    if (!course) {
      throw new Error('课程不存在');
    }
    
    // Check if user already enrolled
    const existingEnrollment = await studyService.getUserCourse(userId, courseId);
    if (existingEnrollment) {
      throw new Error('已加入该课程');
    }
    
    return true;
  }
};
```
