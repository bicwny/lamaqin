
# Practice System Logic & Implementation Guide
# React Native Expo App - 修行追踪 (Practice Tracking)

## Overview
This document outlines the complete practice tracking system architecture, covering all types of practice activities including count-based practices, time-based practices, meditation, study courses, and mindfulness tracking.

## Core Practice Architecture

### 1. Practice Types Classification
The system supports multiple practice tracking methods:

#### A. COUNT-BASED PRACTICES (计数类)
- **Unit**: 次 (times/repetitions)
- **Examples**: 佛号念诵, 礼拜, 大礼拜, 供灯, 供花
- **Tracking Method**: Increment counters for each completion
- **Progress Calculation**: current_count / target_count * 100%

#### B. TIME-BASED PRACTICES (计时类)
- **Unit**: 分钟 (minutes) or 座 (sessions)
- **Examples**: 观修, 禅修, 念佛
- **Tracking Method**: Duration recording with start/stop functionality
- **Progress Calculation**: total_minutes / target_minutes * 100%

#### C. MEDITATION PRACTICES (观修记录)
- **Unit**: 座 (meditation sessions)
- **Special Features**: 
  - 92 specific meditation topics (前行实修法)
  - Reflection recording (观后感)
  - Session numbering
  - Method tracking
- **Progress Calculation**: completed_sessions / 92 * 100%

#### D. STUDY PRACTICES (闻思学习)
- **Unit**: 课 (lessons)
- **Structure**: Courses → Lessons → Study Records
- **Study Types**: 听传承 (listening to teachings), 看法本 (reading texts)
- **Progress Calculation**: completed_lessons / total_lessons * 100%

#### E. MINDFULNESS TRACKING (觉察记录)
- **Unit**: 次 (instances)
- **Categories**: Good mind states vs Bad mind states
- **Tracking Method**: Real-time logging with timestamps
- **Analytics**: Daily/weekly trends, percentage calculations

## Database Schema & Relationships

### Core Tables Structure

#### Users Table
```sql
users:
- id (UUID, primary key)
- dharma_name (法名)
- lay_name (俗名, required)
- email (unique)
- location (所在地区, required)
- class_name (学修班级)
- practice_years (修行年数)
- created_at, updated_at
```

#### Practices Table (修行项目基础表)
```sql
practices:
- id (UUID, primary key)
- name (修行名称: "大礼拜", "佛号念诵", "前行观修")
- type ("count" | "time")
- unit ("次" | "分钟" | "座")
- description (详细说明)
- created_at
```

#### User Practice Projects (用户修行项目)
```sql
user_practice_projects:
- id (UUID, primary key)
- user_id (关联用户)
- practice_id (关联修行项目)
- theme_id (关联主题, nullable)
- target_count (目标数量)
- current_count (当前完成数量)
- daily_target (每日目标)
- start_date (开始日期)
- target_end_date (目标完成日期)
- status ("not_started" | "active" | "completed")
- goal_type ("fixed_duration" | "ongoing")
- target_period ("daily" | "weekly")
```

#### Daily Records (日常修行记录)
```sql
daily_records:
- id (UUID, primary key)
- user_id
- practice_project_id
- record_date (记录日期)
- record_time (记录时间, UTC)
- count (数量)
- notes (备注)
- created_at
```

#### Meditation Records (观修专用记录)
```sql
meditation_records:
- id (UUID, primary key)
- user_id
- practice_id
- record_date
- record_time (UTC)
- duration_minutes (观修时长)
- session_number (第几座)
- method (观修方法)
- reflection (观后感)
- reflection_created_at
- created_at
```

#### Meditation Topics (92个观修主题)
```sql
meditation_topics:
- id (UUID, primary key)
- practice_id (关联前行观修)
- topic_number (1-92)
- title ("思维闲暇之本体", "思维差别之圆满"...)
- description (详细说明)
- created_at
```

### Progress Calculation
```typescript
const calculateCourseProgress = async (userId: string, courseId: string) => {
  // Get total lessons
  const course = await getCourse(courseId);
  
  // Get completed lessons (both 听传承 and 看法本)
  const studyRecords = await getStudyRecords(userId, courseId);
  
  // Group by lesson and check completion
  const completedLessons = groupByLesson(studyRecords)
    .filter(lesson => lesson.听传承 && lesson.看法本);
  
  const progress = (completedLessons.length / course.total_lessons) * 100;
  
  // Update user_courses table
  await updateCourseProgress(userId, courseId, progress);
  
  return progress;
};
```

### Joining Themes
```typescript
const joinTheme = async (userId: string, themeId: string) => {
  // Get all practices in the theme
  const themePractices = await practiceService.getThemePractices(themeId);
  
  const createdProjects = [];
  
  for (const themePractice of themePractices) {
    // Create user practice project for each practice in theme
    const newProject = await practiceService.createUserPracticeProject(
      userId,
      themePractice.practice_id,
      themePractice.target_count,
      Math.ceil(themePractice.target_count / 365), // Daily target
      undefined, // start_date
      undefined, // target_end_date
      'daily',
      themeId
    );
    
    createdProjects.push(newProject);
  }
  
  return createdProjects;
};
```

### Data Validation
```typescript
const validatePracticeRecord = (record: any) => {
  const errors = [];
  
  if (!record.user_id) errors.push('用户ID必填');
  if (!record.practice_project_id) errors.push('修行项目ID必填');
  if (!record.record_date) errors.push('记录日期必填');
  if (record.count <= 0) errors.push('记录数量必须大于0');
  
  if (errors.length > 0) {
    throw new Error(`数据验证失败: ${errors.join(', ')}`);
  }
  
  return true;
};
```

## Performance Optimization

### Caching Strategy
```typescript
// Cache frequently accessed data
const practiceCache = new Map<string, any>();

const getCachedUserPractices = async (userId: string) => {
  const cacheKey = `practices_${userId}`;
  
  if (practiceCache.has(cacheKey)) {
    return practiceCache.get(cacheKey);
  }
  
  const practices = await practiceService.getUserPracticeProjects(userId);
  practiceCache.set(cacheKey, practices);
  
  // Auto-expire cache after 5 minutes
  setTimeout(() => practiceCache.delete(cacheKey), 5 * 60 * 1000);
  
  return practices;
};
```
