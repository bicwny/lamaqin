### FILE-SPECIFIC MIGRATION PLAN

#### Step 1: Update DesignSystem.ts
```typescript
// ADD MISSING TOKENS:
letterSpacing: {
  tight: -0.3,
  tighter: -0.2,    // 🆕 NEW
  normal: 0,
  wide: 0.1,
}
```

#### Step 2: Replace Individual Style Properties
Find and replace each hardcoded style with design token:

```typescript
// BEFORE:
practiceTitle: {
  fontSize: 24,
  fontWeight: '700',
  color: '#1a1a1a',
  letterSpacing: -0.3,
}

// AFTER:
practiceTitle: {
  fontSize: DesignSystem.typography.fontSize['2xl'],
  fontWeight: DesignSystem.typography.fontWeight.bold,
  color: DesignSystem.colors.textPrimary,
  letterSpacing: DesignSystem.typography.letterSpacing.tight,
}
```

#### Step 3: Convert to createStyles Patterns
```typescript
// REPLACE with semantic styles:
practiceTitle: createStyles.heading('2xl'),
progressText: createStyles.heading('lg'),
practiceDescription: createStyles.body('base'),
```

### MIGRATION PRIORITY ORDER:

1. **High Impact, Low Risk** (Start here):
   - practiceTitle, historyTitle, detailsSectionTitle
   - progressText, recordDate, recordCount

2. **Medium Impact, Medium Risk**:
   - Button text styles (primaryButton, secondaryButton)
   - Progress and detail text

3. **Low Impact, Low Risk** (Finish with):
   - Loading states, metadata text
   - Record time, session details
