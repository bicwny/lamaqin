### High-Risk Combinations
1. **Custom letterSpacing values** - Need careful token mapping
2. **Mixed color + typography** - Require semantic color tokens
3. **Context-specific spacing** - May need component-specific tokens

### Migration Order
1. Simple font size replacements (lowest risk)
2. Font weight standardization  
3. Letter spacing consolidation
4. Line height optimization
5. Complex typography + color combinations
