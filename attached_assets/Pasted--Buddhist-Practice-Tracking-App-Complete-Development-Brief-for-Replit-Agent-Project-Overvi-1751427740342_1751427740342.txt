# Buddhist Practice Tracking App - Complete Development Brief for Replit Agent

## 📋 Project Overview

### **Application Purpose**
A comprehensive mobile app for Buddhist practitioners to track practice activities across the complete spiritual path: study, practice, mindfulness cultivation, merit dedication, and selflessness realization.

### **Target Platform**
- **Framework**: Expo React Native (~53.0.9)
- **Backend**: Supabase (PostgreSQL + Auth + Storage)  
- **Development**: Replit environment
- **Deployment**: Cross-platform (iOS/Android/Web)

---

📚 闻思 (study)      - Buddhist study and courses

## 🗄️ Complete Database Schema

### **Core Tables (12 total)**

```sql
-- User Management
users (
  id UUID PRIMARY KEY,
  dharma_name VARCHAR(100),
  email VARCHAR(255) UNIQUE,
  location VARCHAR(100),
  practice_years INTEGER,
  class_name VARCHAR(100),
  created_at TIMESTAMP,
  updated_at TIMESTAMP
)

-- Practice System
themes (
  id UUID PRIMARY KEY,
  name VARCHAR(100) NOT NULL,        -- '五加行', '金刚萨埵法会', etc.
  description TEXT,
  type VARCHAR(50) NOT NULL,         -- 'foundation', 'puja', 'meditation'
  created_at TIMESTAMP
)

practices (
  id UUID PRIMARY KEY,
  name VARCHAR(100) NOT NULL,        -- '顶礼', '百字明', '前行实修法'
  type VARCHAR(50) NOT NULL,         -- 'count' or 'time'
  unit VARCHAR(20) NOT NULL,         -- '次' or '分钟'
  description TEXT,
  created_at TIMESTAMP
)

theme_practices (
  id UUID PRIMARY KEY,
  theme_id UUID REFERENCES themes(id),
  practice_id UUID REFERENCES practices(id),
  target_count INTEGER NOT NULL,     -- 100000 for 五加行
  is_required BOOLEAN DEFAULT true,
  created_at TIMESTAMP
)

-- Course System
courses (
  id UUID PRIMARY KEY,
  name VARCHAR(100) NOT NULL,        -- '《入菩萨行论》'
  total_lessons INTEGER NOT NULL,    -- 201
  teacher VARCHAR(100),              -- '索达吉堪布'
  description TEXT,
  created_at TIMESTAMP
)

course_lessons (
  id UUID PRIMARY KEY,
  course_id UUID REFERENCES courses(id),
  lesson_number INTEGER NOT NULL,
  title VARCHAR(200) NOT NULL,
  content_summary TEXT,
  created_at TIMESTAMP
)

-- User Practice Projects
user_practice_projects (
  id UUID PRIMARY KEY,
  user_id UUID REFERENCES users(id),
  theme_id UUID REFERENCES themes(id),
  practice_id UUID REFERENCES practices(id),
  target_count INTEGER NOT NULL,
  start_date DATE,
  target_end_date DATE,
  current_count INTEGER DEFAULT 0,
  daily_target INTEGER DEFAULT 0,
  status VARCHAR(20) DEFAULT 'not_started', -- 'not_started', 'active', 'completed'
  created_at TIMESTAMP,
  updated_at TIMESTAMP
)

-- Recording Systems
daily_records (
  id UUID PRIMARY KEY,
  user_id UUID REFERENCES users(id),
  practice_project_id UUID REFERENCES user_practice_projects(id),
  record_date DATE NOT NULL,
  count INTEGER NOT NULL,
  notes TEXT,
  created_at TIMESTAMP
)

meditation_records (
  id UUID PRIMARY KEY,
  user_id UUID REFERENCES users(id),
  practice_id UUID REFERENCES practices(id),
  record_date DATE NOT NULL,
  session_number INTEGER NOT NULL,   -- 第几座 (1-92)
  duration_minutes INTEGER NOT NULL,
  session_attempt INTEGER DEFAULT 1, -- 这座的第几次 (1-3+)
  method VARCHAR(100),
  created_at TIMESTAMP
)

study_records (
  id UUID PRIMARY KEY,
  user_id UUID REFERENCES users(id),
  course_id UUID REFERENCES courses(id),
  lesson_id UUID REFERENCES course_lessons(id),
  study_date DATE NOT NULL,
  study_count_for_lesson INTEGER DEFAULT 1,
  created_at TIMESTAMP
)

mindfulness_records (
  id UUID PRIMARY KEY,
  user_id UUID REFERENCES users(id),
  record_date DATE NOT NULL,
  record_time TIME NOT NULL,
  mind_type VARCHAR(10) NOT NULL,    -- 'good' or 'bad'
  description TEXT,
  created_at TIMESTAMP
)

one_time_records (
  id UUID PRIMARY KEY,
  user_id UUID REFERENCES users(id),
  record_date DATE NOT NULL,
  practice_type VARCHAR(50) NOT NULL,
  practice_name VARCHAR(100) NOT NULL,
  count_or_duration VARCHAR(50) NOT NULL,
  notes TEXT,
  created_at TIMESTAMP
)

precept_records (
  id UUID PRIMARY KEY,
  user_id UUID REFERENCES users(id),
  precept_type VARCHAR(50) NOT NULL, -- '八关斋戒', '菩萨戒', etc.
  record_date DATE NOT NULL,
  notes TEXT,
  created_at TIMESTAMP
)
```

## 🔧 Environment Setup Instructions

### **1. Supabase Setup**
1. Create new Supabase project
2. Execute the complete SQL schema provided above
3. Configure Row Level Security (RLS) policies
4. Set up email authentication
5. Get project URL and anon key for environment variables

### **2. Replit Configuration**
1. Create new Replit with Expo React Native template
2. Install additional dependencies listed above
3. Set environment variables:
   ```
   EXPO_PUBLIC_SUPABASE_URL=your_supabase_url
   EXPO_PUBLIC_SUPABASE_ANON_KEY=your_anon_key
   ```
4. Configure TypeScript path aliases in tsconfig.json

### **3. Development Workflow**
1. Start with Phase 1 core features
2. Test each feature thoroughly before moving to next
3. Use Expo development build for testing
4. Regular database backups during development
